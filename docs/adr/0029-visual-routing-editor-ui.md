# ADR 0029: 画面形态分区编辑器 UI

## 状态

Accepted

## 背景

整片规划入口需要让用户看到完整文案，也需要能快速修改每个段落的画面形态。旧工作流使用颜色标注，直观有效。Studio 应继承这个优点，同时提供更清晰的编辑面板。

## 决策

画面形态分区编辑器使用左右双栏：

1. 左侧：完整文案高亮视图。
2. 右侧：当前段落编辑面板。

段落边界遵循 ADR 0030：原文段落优先，AI 建议拆分/合并，用户确认。

## 左侧全文高亮

左侧展示完整文案，按段落或句群高亮：

- 绿色：人物出镜
- 红色：动画
- 黄色：网络现场素材
- 紫色：拍摄

用户点击任意高亮段落，右侧显示该段详情。

## 右侧编辑面板

右侧显示并允许编辑：

- 段落边界建议
- 画面形态
- 分区理由
- 素材建议
- 进入动画制作
- 备注

当 `visual_mode` 为 `animation` 时，右侧显示“进入动画制作”按钮。点击后为该段落创建动画制作片段，并进入制作计划流程。

## 边界编辑

第一版支持：

- 确认 AI 推荐边界
- 拆分当前段落
- 合并相邻段落
- 修改段落颜色
- 编辑备注

所有修改同步写入 `visual-routing.yaml`。

## 影响

- AI 输出的画面形态计划需要保留段落边界。
- Studio 需要支持点击段落并更新 `visual_mode`。
- 用户修改颜色时，应同步更新 YAML。
- 动画段落可以从右侧直接进入动画制作入口。
