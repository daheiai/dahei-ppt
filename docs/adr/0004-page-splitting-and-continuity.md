# ADR 0004: 拆页与连续性

## 状态

Accepted

## 背景

一段文案经常包含多个重点。把多个重点塞进同一页会削弱视觉中心，也会让观众不知道该记住什么。视频又需要连续性，频繁切断会降低观看流畅度。

`dahei-ppt` 已有 Magic Move 经验：当元素在页面切换时没有本质变化，应保持元素连续移动，而非消失后重新出现。

## 决策

多重点内容采用“先拆页，再允许 Magic Move”的策略。

规则：

1. 每页只保留一个视觉主角。
2. 多个重点优先拆成多页。
3. 如果连续页面共享同一个主角，主角可以跨页保留并移动。
4. 新重点出现时，旧主角可以退到陪衬位置。
5. 观众注意力通过主角移动、缩放、连接、淡出和替换完成迁移。

## 影响

- 制作计划需要声明 `visual_subject`。
- 制作计划需要声明 `continuity_group`。
- HTML 生成需要支持跨页独立层。
- 质量检查需要验证每页主角唯一。
- MP4 渲染需要保留跨页动效的时序。

## 示例

一段讲稿：

> 模型能力不只取决于模型本身，还取决于上下文、工具调用和权限治理。

推荐拆解：

1. 页面 A：主角是模型。
2. 页面 B：模型缩小或移动，主角变成上下文。
3. 页面 C：上下文退到陪衬，主角变成工具调用。
4. 页面 D：工具调用退到陪衬，主角变成权限治理。
5. 页面 E：模型、上下文、工具调用、权限治理共同组成结构图，主角变成整体关系。

## 待继续追问

- 主角跨页连续时，移动速度和路径如何默认化。
- 旧主角退场时应变成陪衬、灰化、缩小，还是移到边缘。
- 同一组连续页面最多允许几个页面。
