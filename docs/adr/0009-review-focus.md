# ADR 0009: 制作计划确认重点

## 状态

Accepted

## 背景

制作计划用于在生成 HTML 前减少返工。用户确认时最重要的是判断内容是否抓准，而不是检查每个技术细节。

## 决策

制作计划确认重点为：

1. 视觉主角
2. 页面文字

页数、模板、顺序和动效也可以修改，但默认展示时应让视觉主角和页面文字最醒目。

## 影响

- Markdown 制作计划优先展示视觉主角和页面文字。
- 系统生成计划时需要特别审查主角是否唯一。
- 页面文字应尽量接近用户表达风格。
- 模板选择可以交给系统，低信心或复杂页面才解释。

## 待继续追问

- 页面文字应更像标题、字幕、标签，还是口播摘要。
- 视觉主角抓错时，用户希望用何种短指令修改。
