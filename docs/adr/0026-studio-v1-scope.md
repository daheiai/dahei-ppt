# ADR 0026: Studio v1 范围

## 状态

Accepted

## 背景

Studio 是 `dahei-ppt` 的可视化生产工作台。第一版如果只做 CLI，创作流程仍然偏工程化。用户希望进入一个完整 UI 来管理文案、制作计划、HTML 预览和导出。

## 决策

Studio 第一版做完整 UI。

完整 UI 指覆盖第一版闭环：

1. 项目列表
2. 整片文案输入
3. 画面形态分区编辑器
4. 动画段落制作计划展示和确认
5. HTML 预览
6. MP4 导出状态和结果入口

## 第一版范围边界

- 复杂时间线编辑器进入后续版本。
- 拖拽式视觉编辑器进入后续版本。
- 多人协作进入后续版本。
- 云端渲染进入后续版本。

## 影响

- 需要使用前端框架搭建 Studio。
- CLI 仍然保留，Studio 调用 CLI。
- 文件系统仍然是项目源数据。
- Studio v1 重点是把流程串起来。
- 前端技术栈见 ADR 0031。
