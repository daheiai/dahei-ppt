# ADR 0006: 默认拆分粒度

## 状态

Accepted

## 背景

`dahei-ppt` 的主入口是一段讲稿或文案。系统需要自动拆成页面和镜头。如果拆得过细，视频会碎；如果拆得过粗，页面会满，视觉主角也会混乱。

## 决策

默认拆分粒度为中等：

- 每页一个视觉主角。
- 每 1 到 2 句生成一页。
- 一个判断、一个关系、一个例子可以独立成页。
- 同一主角的连续解释可以形成连续组。
- 多个主角必须拆页。

## 影响

- 文案拆解阶段先按语义切分，再按视觉主角切分。
- 页面数量服务清楚表达，而不是追求少页。
- 制作计划需要记录每页对应的原文片段。
- MP4 导出节奏需要支持每页 2 到 6 秒的默认时长。

## 默认时长建议

- 大字观点页：2-3 秒
- 概念定义页：3-4 秒
- 关系图页：4-6 秒
- 对比页：4-6 秒
- 案例截图页：4-7 秒
- 总结收束页：3-5 秒

## 待继续追问

- 用户是否希望制作计划在生成 HTML 前可确认。
- 页面数量多时，是否需要自动生成小节分组。
- 短视频和长视频是否使用不同粒度。
