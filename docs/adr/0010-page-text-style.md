# ADR 0010: 页面文字风格

## 状态

Accepted

## 背景

`dahei-ppt` 的画面文字需要服务视觉记忆点。解释性内容主要由口播承担，画面承担结构、关键词和重点强调。

## 决策

页面文字采用混合式：

1. 主文字使用标题式表达。
2. 辅助信息使用标签式表达。
3. 口播解释留在旁白或原文依据中。

## 影响

- 制作计划中的页面文字应分为主文字和辅助标签。
- HTML 生成时优先展示短标题、关键词、结构标签。
- 长句进入旁白依据，避免进入画面主体。
- 质量检查需要验证文字是否足够短、足够集中。

## 示例

主文字：

> Step3.5Flash

辅助标签：

> AI 模型
> 角色定义
> 工具调用
> 权限治理

旁白依据：

> 切换中间模型后，最终效果和价格都会跟着变化。
