# ADR 0005: 主角退场策略

## 状态

Accepted

## 背景

连续页面可以通过 Magic Move 保持视觉主角的连续性，但保留旧主角会增加画面密度。`dahei-ppt` 的第一原则是精简，因此旧主角完成表达后应尽快离场。

## 决策

默认退场策略是直接淡出。

保留旧主角只适用于强连接场景：

- 同一段内容始终围绕同一个对象展开。
- 旧主角是后续理解所需的参照物。
- 页面正在逐步累计成一张结构图。
- 旧主角退到陪衬位置后依然能帮助理解。

退场优先级：

1. 直接淡出
2. 缩小到边缘
3. 灰化降权
4. 移动到结构图里

如果保留旧主角导致页面出现多个竞争性视觉中心，应退回直接淡出。

## 影响

- Magic Move 是连续性工具，不是默认装饰。
- 制作计划需要声明保留原因。
- 质量检查需要检查旧元素是否造成视觉冗余。
- 模板应默认让完成使命的元素离场。
