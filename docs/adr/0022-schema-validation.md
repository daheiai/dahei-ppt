# ADR 0022: 制作计划 Schema 校验

## 状态

Accepted

## 背景

制作计划是从文案到 HTML/MP4 的核心中间产物。它既需要被人确认，也需要被生成器读取。字段错误、缺失字段和模板名称错误都应尽早暴露。

## 决策

第一版使用 Zod 定义和校验制作计划 schema。

## 采用理由

- 与 TypeScript 生态匹配。
- 一套定义同时服务类型推导和运行时校验。
- 适合 CLI 在生成 HTML 前做校验。
- Codex 生成代码时可以参考明确 schema。

## 影响

- 项目依赖加入 `zod`。
- 制作计划加载流程必须经过 schema 校验。
- 校验失败时 CLI 输出具体字段错误。
- 后续如需要编辑器校验，可再导出 JSON Schema。

## 待继续追问

- 制作计划 schema 第一版包含哪些必填字段。
- 模板名称是否使用枚举。
- 是否允许用户自定义模板字段。
