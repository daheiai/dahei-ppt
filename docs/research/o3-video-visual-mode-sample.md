## 样本观察

这个样本里的画面形态分流有几个明显模式：

1. 人物出镜承担“连接”和“判断”。
2. 动画承担“结构化”和“总结”。
3. 网络素材承担“证据”和“实测过程”。
4. 拍摄承担“现实情境”和“小剧场”。

## 对 dahei-ppt 的启发

完整文案进入系统后，第一步应生成“画面形态计划”，再对动画段落生成制作计划。

画面形态计划的字段建议：

```yaml
segments:
  - id: segment_01
    source: "原文片段"
    visual_mode: "talking_head | animation | web_source | live_shoot"
    reason: "为什么选择这种画面形态"
    animation_candidate: true
```

其中只有 `animation_candidate: true` 的段落进入 `dahei-ppt` 动画生成链路。
